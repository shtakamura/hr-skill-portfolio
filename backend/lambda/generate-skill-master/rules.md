# スキル生成ルール

- スキル件数に上限を設けない
- 職務を説明するために必要なスキルだけを抽出する
- スキル数を増やすこと自体を目的としない
- 部署名、役職名、ポジション名をスキル名にしない
- タスク名や成果物名をそのままスキル名にしない
- 製品名やツール名は必要に応じて汎用的な能力へ抽象化する
- 汎用スキルと専門・職能スキルが混在してもよい
- 意味的に重複するスキルは可能な限り統合する
- 既存スキルで説明できる場合は類似スキルを追加しない
- skill_nameだけでなくdefinitionの意味も踏まえて重複を判断する
- 全スキルに日本語のdefinitionを付ける
- definitionは原則「〜する能力」の形式にする
- 有効なJSONだけを返す
- MarkdownコードフェンスやJSON前後の説明文を付けない
- 同一またはほぼ同一のskill_name・definitionを複数返さない
