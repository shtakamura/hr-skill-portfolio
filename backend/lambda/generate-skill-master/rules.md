# スキル生成ルール

- スキル件数に上限を設けない
- 職務を説明するために必要なスキルだけを抽出する
- 部署名、役職名、ポジション名、タスク名、成果物名をそのままスキル名にしない
- 製品名やツール名は必要に応じて汎用的な能力へ抽象化する
- 意味的に重複するスキルは統合する
- 同一またはほぼ同一のskill_nameやdefinitionを複数返さない
- 全スキルに日本語のdefinitionを付与する
- definitionは原則「〜する能力」の形式にする
- 有効なJSONのみを返す
- JSON以外の文字を出力しない
- Markdownコードフェンスを付けない
- JSONの前後に説明文を付けない

重要:

出力形式は必ず以下とする。

{
  "skills": [
    {
      "skill_name": "スキル名",
      "definition": "定義"
    }
  ]
}

- トップレベル項目はskillsのみとする
- skill_nameやdefinitionをトップレベルへ出力してはならない
- skillsは必ず配列とする
- スキルが1件の場合でも配列とする
- skillsの各要素はJSONオブジェクトとする
- skill_masterやresultなどのラッパーオブジェクトを追加してはならない
- 空のskills配列を返してはならない
